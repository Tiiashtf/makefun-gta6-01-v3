Solmar Bay is a 3D open-world crime game in the spirit of GTA 6: explore a seeded coastal city on foot and by car, steal cars, outrun a 0–5 star wanted system with police chases, fight through six story missions, and take the Bay back from crime boss Victor Kaine — all offline in the browser with three.js.

## Controls

WASD move / drive · mouse drag to orbit the camera · E enter / exit car · click punch / shoot · Q switch weapon · Shift run · Space handbrake · R restart mission · Esc pause · M mute. Progress autosaves every 25 seconds; Continue on the title screen picks up where you left off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
